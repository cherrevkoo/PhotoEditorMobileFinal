# Photo Editor Mobile

Мобильное приложение для редактирования фотографий на Android, разработанное с использованием Jetpack Compose и Material Design 3.

## Описание проекта

Photo Editor Mobile — это полнофункциональный редактор фотографий, позволяющий пользователям применять различные фильтры, эффекты, настройки и инструменты для обработки изображений.

### Основные технологии

### Библиотеки:
- GPUImage — библиотека для применения фильтров и эффектов с использованием GPU
- Glide — библиотека для загрузки изображений
- Kotlin
- Jetpack Compose, Material 3


### Библиотеки

- **GPUImage** — фильтры и эффекты на GPU
- **Glide Compose** — загрузка изображениц
