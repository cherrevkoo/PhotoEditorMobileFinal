# Photo Editor Mobile

Мобильное приложение для редактирования фотографий на Android, разработанное с использованием Jetpack Compose и Material Design 3.

## Описание проекта

Photo Editor Mobile — это полнофункциональный редактор фотографий, позволяющий пользователям применять различные фильтры, эффекты, настройки и инструменты для обработки изображений. Приложение предоставляет интуитивный интерфейс и базовый набор возможностей для творческой обработки фотографий.

### Основные технологии:
- Kotlin — основной язык разработки
- Jetpack Compose — современный UI toolkit для Android
- Material Design 3 — система дизайна для создания интерфейса
- Android Architecture Components**:

### Библиотеки:
- GPUImage — библиотека для применения фильтров и эффектов с использованием GPU
- Coil — библиотека для загрузки и кэширования изображений
- Jetpack Compose BOM — управление версиями Compose библиотек


## Основные возможности

### Фильтры
- Сепия
- Черно-белый
- Негатив
- Постеризация
- Эскиз
- Винтажный
- Мягкий свет
- Рейес
- Луна
- Ларк


### Настройки изображения
- Яркость — регулировка яркости изображения
- Контраст — изменение контрастности
- Насыщенность — управление насыщенностью цветов
- Теплота — корректировка цветовой температуры
- Резкость — улучшение четкости изображения

### Обрезка
- Свободная обрезка
- Предустановленные соотношения сторон:
  - 1:1 
  - 4:3
  - 3:4
  - 16:9
  - 9:16

### Трансформации
- Поворот на произвольный угол
- Поворот на 90° по часовой и против часовой стрелки
- Отражение по горизонтали
- Отражение по вертикали

### Эффекты
- Виньетка (мягкая и сильная)
- Зерно
- Радиальное размытие
- Мягкий фокус

### Пресеты
- Сохранение комбинаций настроек как пресетов
- Применение сохраненных пресетов одним нажатием
- Управление коллекцией пресетов

### Экспорт
- Экспорт в различных форматах:
  - JPEG
  - PNG
  - WEBP
- Настройка качества экспорта 
- Сохранение в галерею устройства

### История изменений
- Отмена действий
- Повтор действий 
- Сохранение истории всех изменений

### Сравнение
- Просмотр оригинального изображения для сравнения с отредактированным
- Быстрое переключение между оригиналом и результатом
